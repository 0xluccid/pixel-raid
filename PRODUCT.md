# Pixel Raid — Product Context

## What is it?
Pixel Raid is a browser-based trading card battle game with pixel art aesthetics. Players collect hero cards with elemental affinities, build decks, form synergies, and battle in a turn-based auto-battler system.

## Audience
- Hackathon judges (demo showcase)
- Web3/crypto gaming enthusiasts
- Retro gaming & pixel art fans
- TCG/card game collectors

## Brand Voice
- Energetic, playful, slightly competitive
- Pixel art nostalgia + modern gaming polish
- Dark theme with neon element accents

## Product Lane
App UI (game interface, not marketing)

## Core Screens
1. **Home/Menu** — Player profile, navigation
2. **Collection** — All owned cards, search, filter, sort
3. **Strategy** — Hero pick + deck building (4 cards max)
4. **Battle** — Turn-based auto-battler with phased combat
5. **AI Deck Builder** — AI-powered deck recommendations (mock)
6. **AI Coach** — Post-battle AI analysis (mock)

## Key Mechanics
- 5 Elements: Fire 🔥, Water 💧, Nature 🌿, Lightning ⚡, Shadow 🌑
- Heroes have stats (HP, ATK, DEF, SPD) + one active ability
- Synergy system: matching types = bonus stats
- Battle phases: DRAW → ENERGY → PLAY → ARRANGE → BATTLE → END
- Formation grid: 3x2 (front row tanks, back row DPS)

## Design Constraints
- Vanilla JS + Phaser.js (no React/Vue/Angular)
- Must run in browser, mobile-friendly
- No backend — mock data for AI features
- 3-minute hackathon demo flow
- Dark theme mandatory
